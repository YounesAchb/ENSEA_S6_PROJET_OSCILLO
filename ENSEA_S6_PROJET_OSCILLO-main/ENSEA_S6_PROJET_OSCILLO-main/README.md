# ENSEA_S6_PROJET_OSCILO
Projet de S6 , réalisation d'un Oscilloscope Smartphone    
## Etudiants concernés
* Yassine JABOU
* Younes ACHBAD
* Gabriel BOUDOUX D'HAUTEFEUILLE
* Gökay OZDEN
         
## Abstract     
Le but du projet est de réaliser un système embarquée agissant comme un oscilloscope. Celui ci serait composé de deux parties :      
1. Un boitier qui reçoit le signal, le numérise puis le transmet au display
2. Une interface sous forme d'application Java qui permet la visualisation des signaux et le contrôle de l'oscilloscope via bluetooth

## Spécifications du projet 
1. Performances attendues     
1.1. Nombres d'entrées : 2     
1.2. BP : 10 Hz - 50 kHz    
1.3. Points par captures : 1024 (mode double) ou 2048 (mode simple)
1.4. Lecture direct et nette d'un signal    
1.5. Transmission bluetooth d'un signal à l'application mobile sans dégradation   
1.6. Système embarqué faible puissance (obj. 6h d'autonomie)
